## 🚀 Setup

### Prerequisites
- Web browser (Chrome, Firefox, Safari, Edge)
- Web server (optional, for local development)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/portfolio-youssef-atef.git
   cd portfolio-youssef-atef
   ```

2. **Open the project**
   - Open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx http-server
     
     # Using PHP
     php -S localhost:8000
     ```

3. **Access the website**
   - Navigate to `http://localhost:8000`

## 🎯 Key Features Details

### 🌐 Language Toggle
- Button في الناف بار للتبديل بين العربية والإنجليزية
- حفظ التفضيلات تلقائياً
- تحديث جميع النصوص ديناميكياً

### 🌓 Dark Mode Toggle
- زر في الناف بار لتفعيل/إلغاء Dark Mode
- تأثيرات انتقال سلسة
- دعم كامل لجميع العناصر

### 📱 Mobile Navigation
- قائمة منسدلة جميلة للجوال
- تصميم محسّن للشاشات الصغيرة
- تأثيرات بصرية جذابة

### 🎨 Animations
- Skill bars animations عند التمرير
- Counter animations للإحصائيات
- Hover effects على جميع العناصر
- Smooth scrolling

### 📧 Contact Form
- تكامل مع FormSubmit.co
- Validation كامل
- رسائل نجاح/خطأ
- دعم اللغتين
